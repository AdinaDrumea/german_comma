# Komma-Detektive

German comma practice app for Klasse 6/7, adapted for Swiss Standard German.

## Files to upload to GitHub Pages

Upload these four files to the repository root:

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

They replace the corresponding files from the previous version.

## Important when updating the existing repository

1. Replace the old `index.html`, `styles.css`, and `app.js` with these versions.
2. Replace the old `README.md` if desired.
3. Do not upload `komma-detektive-prototype-v3.html`; it was only a prototype preview and is not needed.
4. GitHub Pages can continue using the same branch/root configuration as before.

## What this version includes

- comprehensive comma-rule information panel
- practice with subordinate-clause connectors
- many `daran / darauf / darüber / dagegen ...` examples without a second connector clue
- contrast examples with `dass / ob / was`
- subordinate clause first
- relative clauses / inserted clauses with two commas
- expanded Fehlerdetektiv exercises
- mixed practice
- local score storage in the browser

No framework or external dependency is required.
